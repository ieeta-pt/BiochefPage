### Key behaviors
- Aggregator orchestrates rounds, eligibility, and scoring.
- Agents train locally; only updates/metrics leave the silo.
- Models published back to registry with signed lineage.

### Practical tips
- Define DP/aggregation policies per session.
- Provide capability manifests per silo (GPU, data domains).
- Use Observability to detect stragglers or outliers early.
```json
{
  "session": "fl-cnv-001",
  "aggregator": "https://agg.bio/fl",
  "trainer": "oci://ghcr.io/org/biochef/trainers/cnv@sha256:...",
  "dp": { "epsilon": 4, "delta": 1e-5 },
  "policy": { "minSilos": 3, "secureAggregation": true }
}
```
