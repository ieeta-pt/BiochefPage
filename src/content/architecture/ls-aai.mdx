### Key behaviors
- UI uses OIDC (Authorization Code + PKCE) to authenticate users.
- Aggregator validates JWTs (JWKS) for federated APIs and enforces roles.
- Agents may use client credentials for service-to-service operations if allowed.

### Practical tips
- Keep scopes minimal and map entitlements to BioChef roles (viewer, operator, admin).
- Rotate client secrets; prefer private_key_jwt or mTLS where supported.
- Propagate user identity into observability events for auditability (without PII).
