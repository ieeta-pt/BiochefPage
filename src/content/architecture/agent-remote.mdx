### Key behaviors
- Executes signed tasks near data; enforces storage/egress policies.
- Integrates GA4GH data APIs; supports sidecars and GPUs.
- Can forward selected steps to TES/WES while keeping lineage.

### Practical tips
- Configure allowed registries and TLS for pull/push operations.
- Separate queues for interactive vs. batch jobs.
- Emit logs/metrics to Observability sink for troubleshooting.
