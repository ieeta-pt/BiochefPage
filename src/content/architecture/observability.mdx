### Key behaviors
- Structured events for start/stop/error plus custom metrics.
- Lineage links artifacts to recipe version, runtime, and dataset.
- Feeds dashboards and alerts for Ops/DS teams.

### Practical tips
- Emit structured JSON; avoid freeform logs for key signals.
- Redact PII at source; enforce per-tenant sinks for silos.
- Correlate runs with registry digests for reproducibility.
```json
{
  "runId": "uuid",
  "artifactDigest": "sha256:...",
  "runtime": "agent",
  "events": [
    { "type": "start", "ts": "..." },
    { "type": "metric", "name": "cpu_pct", "value": 72 },
    { "type": "end", "status": "success", "ts": "..." }
  ]
}
```
