### Key behaviors
- Serves capabilities from registry catalog with signatures.
- Provides actions for run/describe/publish guarded by policy.
- Streams observability summaries back to the calling agent.

### Practical tips
- Keep scopes narrow; map agent roles to BioChef policies.
- Cache catalog responses but re-verify signatures periodically.
- Surface redaction rules so LLMs avoid sensitive fields.
