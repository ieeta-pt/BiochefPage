1. A developer opens a PR on `biochef-recipes` adding `recipes/<tool>/biochef.yaml` and its build script (`build-wasm.sh`, and `build-native.sh` for a native build).
2. On the PR, the reusable workflow from `biochef-hub` runs `validate` → `build` (Emscripten/biowasm, or native) → `test` (each tool on the example input of its data types) → `sbom` → `sbom-check`.
3. After merge, it runs `publish` to the BioChef Registry → `sign-attest` (keyless cosign) → `verify-attestations`, generates and verifies SLSA provenance, and `publish-catalog` writes the signed `index.json` catalogue with the new digest.
4. The next time the BioChef web app loads, it sees the new tool in the catalog and can fetch its WebAssembly bundle by digest.
